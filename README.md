# Calculator Web App

A simple and clean calculator web application built using **HTML, CSS, and JavaScript**.  
It performs basic arithmetic operations with a user-friendly interface.

---
# Features in this webapp:-

- Addition
- Subtraction
- Multiplication
- Division
- Clear (C) button
- Backspace / Cut (⌫) button
- Clean and responsive UI
- Safe logic (no use of `eval()`)

---

# Technologies Used

- HTML5
- CSS3
- JavaScript
